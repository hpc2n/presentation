# Exercises

The exercises can be found in the subdirectory for the centres: ``hpc2n``, ``lunarc``, ``uppmax``, ``nsc``, ``pdc``, ``c3se``. 

In each centre directory, there are two subdirectories: ``slurm`` and ``modules`` each with exercises for the specific part. 

**NOTE** that 
- if you are not working at NSC, PDC, or HPC2N you will have to change the "project ID" to the project account ID you have at that centre. 
- if you are working at C3SE you can only really run GPU jobs
